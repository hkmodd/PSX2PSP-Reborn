# S7: release work brought forward

## Memory card (S7a)

Sheep Dog checks the card before its main menu, so gameplay is unreachable without one; the
card comes before the remaining S4c and S5 work.

- **Level:** the BIOS, not the SIO port. libcard's primitives (`_card_info`, `_card_load`,
  `_card_read`, `_card_write`, `_new_card`), the card file API on "bu00:"/"bu10:" (open with
  create, read, write, lseek, close, firstfile/nextfile, erase, format) are answered in
  `core/card.c` on a 128 KB image in Sony's layout, interchangeable with other emulators' .mcr.
- **Completion:** at once. The HwCARD/SwCARD events (IOE, or TIMEOUT for an empty slot) are
  delivered before the call returns; an async file operation returns 0 and raises them, a
  synchronous one returns the byte count.
- **Host:** slot 0 is `card0.mcr` beside the EBOOT, created formatted when missing; slot 1 is
  empty. The image is written back 30 frames after the last change and at exit.
- **Result:** the card check passes, the menu and a new game are reached (the intro scene at
  100% speed, ~40k polygons/s). A save made by the game is not yet tested.

## Test harness

- **Scripted pad:** `psxrt.pad` beside the EBOOT, lines of "frame buttons(hex) frames", ORed
  into the pad state; up to 256 presses. Reaches gameplay without a person at the keyboard.
- **Shots:** `psxrt.shots` lists frame numbers; at each one the displayed area is read back
  from VRAM and written as `shotNNNNN.bmp` (24-bit, 15-bit and 24-bit modes). It replaces
  host screenshots, which need an unlocked desktop.
- **BIOS log:** an unimplemented BIOS function is logged once, not at every call.
